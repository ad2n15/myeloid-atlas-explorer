# Myeloid Atlas Explorer

Interactive, static explorer of two curated single-cell RNA-seq atlases of clonal haematopoiesis
and myeloid neoplasms: **BM25** (bone marrow / CD34⁺ progenitors, 25 studies) and **PBMC4**
(blood, 4 studies). Live site: https://ad2n15.github.io/myeloid-atlas-explorer/

- Colour cells by curated Level 1 / Level 2 cell types, CellTypist and author labels, study,
  donor, condition, sex, QC metrics, gene expression or per-cell cytokine-response scores
  (huCIRA Human Cytokine Dictionary signatures).
- Compare genes across cell groups (dot plots, distributions) and check label agreement.
- Browse the donor-level results (meta-analysis of cytokine-response signatures, response modules,
  cell-type composition). Response modules follow the huCIRA paper's highly similar cytokine groups
  (Oesinghaus et al. 2025, Supplementary Table 11: Interferon response, γc cytokines, type 2,
  OSM/IL-17C/IGF-1), fixed across cell types; other cytokines are shown singly.
- Donor-level tests follow a cell-count rule: a comparison × cell type is tested (reported with a q value
  and included in the FDR correction) only if donors hold a median of ≥ 100 cells of that type in each arm;
  other analyses are shown in grey, marked "n.t.", as descriptive effects without q values. One GSE285943
  donor labelled "cytopenia (MF?)" (diagnosis uncertain) is excluded from the donor-level analyses.
- Explore the original cell-level huCIRA analysis of the clonal haematopoiesis cohort (Heimlich 2024),
  side by side with its donor-level counterpart.

Each atlas is shown as a stratified subsample of cells (every curated cell type × study kept;
rare types kept whole). Data come from public GEO and CELLxGENE studies listed in the app's
About tab; please cite the original studies. Per-cell scores are descriptive; the statistics are
donor-level.

The site is plain HTML/JS (no build step): `index.html`, `app.js`, `style.css`, data in `data/`
(format: `DATA_FORMAT.md`). It is generated by `scripts/build_explorer.py` in
https://github.com/ad2n15/cytokines-mediated-inflammation.
Libraries: regl-scatterplot 1.14.1, Plotly.js 2.35.2 (loaded from CDNs).
